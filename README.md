# Blistiq Tools

A collection of fast, lightweight, and privacy-focused PDF utilities. All processing happens 100% locally in your web browser, meaning **your files are never uploaded to any server**.

🔗 **[Live Demo](https://pinkeshbadjatiya.github.io/blistiqtools/)** *(Update this link if deploying to Vercel)*

## 🛠️ Available Tools

1. **PDF Merger (`index.html`)**
   * Select multiple PDF files from your device.
   * Instantly combines them into a single continuous PDF document.
   
2. **4-in-1 PDF Maker (`4up.html`)**
   * Upload a standard PDF.
   * Automatically scales and arranges 4 pages onto a single standard A4 sheet.
   * Perfect for saving paper when printing lecture slides, notes, or long documents.

## ✨ Features

* **Privacy First:** Built completely client-side using JavaScript. Your sensitive documents never leave your device.
* **Mobile Friendly:** Fully responsive design that works flawlessly on phones, tablets, and desktops.
* **Fast Processing:** Uses modern browser capabilities to process documents almost instantly.
* **No Backend Required:** Completely static files, making it free and easy to host indefinitely.

## 💻 Tech Stack

* **HTML/JavaScript** for structure and logic.
* **[Tailwind CSS](https://tailwindcss.com/)** (via CDN) for rapid, responsive styling.
* **[pdf-lib](https://pdf-lib.js.org/)** for reading, modifying, and generating PDF documents directly in JavaScript.
